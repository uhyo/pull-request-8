# プルリクエスト #8

▶ https://uhyo.github.io/pull-request-8/

AI が書いたプルリクエストを、**説明文だけ**でレビューする異変探しゲームです。

## 遊び方

難易度（かんたん・ふつう・むずかしい）を選ぶと、いつもの AI（`codebot[bot]`）から次々とプルリクエストが届きます。
内容は毎回違いますが、説明文はいつも同じ書き方です。
難しいほど説明文が長く、込み入ったものになります（むずかしいは準備中）。
ふつうでは、AI がやってはいけないことをしたり、ありもしないことを書いたりする異変が中心です。

- いつもどおりの説明文なら **承認**
- どこかに異変があれば **変更をリクエスト**
- 正しく判断すると番号が 1 つ進み、間違えると **#1** に戻ります
- 間違えたあとは、そのプルリクエストの答え合わせができます（見逃した異変がどこにあったかを確認できます）
- **#8** を正しく承認できたらマージされてクリア

差分（変更ファイル）は見られません。説明文を信じるしかありません。
見つけた異変は難易度ごとに図鑑としてブラウザに保存されます（答え合わせで見ただけの異変は数えません）。

## 開発

```sh
npm install
npm run dev      # 開発サーバー
npm test         # テスト（Vitest）
npm run build    # 型チェック + dist/ に出力
```

- `src/levels/index.ts` — 難易度の一覧（`problems: null` は準備中）
- `src/levels/easy/` — かんたんのプルリクエスト（1 ファイルに 1 つ）と、それぞれの異変
  - `index.ts` — かんたんで届くプルリクエストの一覧（ここに足せば増やせます）
  - `common.ts` — かんたんの説明文のテンプレートと、どのプルリクエストにも起こりうる異変
- `src/levels/normal/` — ふつうのプルリクエスト（かんたんと同じ構成）
- `src/levels/codebot.ts` — `codebot[bot]` のプルリクエストで毎回同じになる部分
- `src/anomalies.ts` — 異変を作るための補助関数
- `src/pr.ts` — プルリクエストの型
- `src/game.ts` — 進行ロジック（番号・判定・異変の抽選）
- `src/diff.ts` — 答え合わせで、いつものプルリクエストとの違いを求める
- `src/main.ts` — 画面の描画と演出

## デプロイ

`master` に push すると GitHub Actions がテスト・ビルドして GitHub Pages に公開します
（`.github/workflows/deploy.yml`）。リポジトリの Settings → Pages で
Source を「GitHub Actions」にしておく必要があります。
